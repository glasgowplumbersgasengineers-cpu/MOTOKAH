# Motokah Automated SEO + Customer Growth Plan

## What Is Automated In The Repo

- `npm run build` regenerates `public/sitemap.xml`.
- Sitemap includes priority countries, cities, dealers, showrooms, model pages and curated search pages.
- Homepage internal links point to top countries, cities, models, dealer pages and city-model searches.
- Search pages generate canonical URLs, collection schema and FAQ schema.
- Dealer contacts page is indexable and linked from header/footer.
- Store screenshots and mobile release tooling are available for app launch.

## Daily Loop

1. Check top dealer/listing pages for broken images.
2. Add or refresh 5-10 high-quality dealer listings.
3. Run `npm run build` to refresh sitemap dates.
4. Push to `main` so Vercel redeploys.
5. Post one Instagram item from a real dealer/listing page.
6. Send 10 WhatsApp dealer claim messages from `launch/dealer-whatsapp-messages.md`.

## Weekly Loop

1. Add 3 new city/model search combinations to sitemap only if there is inventory or a strong dealer page.
2. Add one useful blog/buying guide page for a real keyword.
3. Update Google Business Profile manually until API posting is wired.
4. Resubmit sitemap in Google Search Console.
5. Inspect these URLs in Search Console:
   - `/`
   - `/country/tanzania`
   - `/city/dar-es-salaam`
   - `/dealer/dealer-mgayamotors`
   - `/dealer/dealer-ibaraki`
   - `/search?make=Toyota&model=Hilux&country=Tanzania`

## Instagram Role

Instagram will not directly make Google rank Motokah number one quickly, but it helps because:

- Dealers can share their Motokah pages.
- Branded search for "Motokah" increases.
- Fresh vehicle pages get real clicks.
- Buyer/dealer trust improves when the same stock is visible on social and site.

Only post real inventory, dealer spotlights, buyer safety, city/model searches and claim-your-page content. Do not post fuel news, accident news, politics or generic RSS-style posts.

## What Still Needs Credentials

- Valid Instagram Graph long-lived token for automated posting.
- Google Search Console API credentials if we want automated URL inspection requests.
- Google Business Profile OAuth if we want automated GBP updates.
- Play Console account and signed Android upload key for public app release.

## Growth Targets

- First 14 days: 20 dealer conversations, 10 claimed pages, 100 buyer call/WhatsApp clicks.
- First 30 days: 50 dealer conversations, 25 claimed pages, 500 buyer actions, 1,000 branded/direct visits.
- First 90 days: own Tanzania long-tail searches such as Toyota Hilux Tanzania, Toyota Harrier Dar es Salaam, car dealers Dar es Salaam, used cars Tanzania.
