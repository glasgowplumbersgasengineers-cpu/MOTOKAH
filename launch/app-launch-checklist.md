# Motokah App Launch Checklist

## Android
- Build debug APK for phone testing.
- Create upload keystore and keep it backed up safely.
- Build signed release AAB.
- Upload AAB to Play Console internal testing.
- Add screenshots, description, privacy policy and data safety.
- Test install from Play internal testing link.

## iOS
- Move repo to a Mac.
- Install Xcode.
- Run `npm run build:ios`.
- Open `ios/App/App.xcodeproj`.
- Set Apple Team, bundle id and signing.
- Archive and upload through Xcode Organizer.

## Product
- Confirm login, post ad, wishlist, search, dealer pages and listing detail on mobile.
- Confirm location selection changes search defaults.
- Confirm broken-image count is zero on top pages.
- Confirm app splash/icon are branded.

## Growth
- Contact first 20 dealers.
- Publish daily Instagram content.
- Add Google Business Profile posts manually until API posting is wired.
- Ask dealers to share their Motokah page.
- Track calls/WhatsApp clicks weekly.
